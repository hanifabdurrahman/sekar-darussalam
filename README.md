# Sekar Darussalam Islamic Village

Landing page resmi Sekar Darussalam Islamic Village, hunian syariah yang berlokasi di Klaten.

## Fitur

- Informasi keunggulan kawasan
- Rumah Tahfidz
- Video kawasan
- Siteplan kawasan
- Tipe unit rumah
- Video interior
- Legalitas & pengembangan kawasan
- Skema pembayaran
- Integrasi WhatsApp

## Teknologi

- React
- TypeScript
- Vite
- Tailwind CSS
- Motion

## Menjalankan Project

Install dependencies:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Build production:

```bash
npm run build
```

Preview hasil build:

```bash
npm run preview
```

## Deployment

Project dapat di-deploy menggunakan:

- Cloudflare Pages
- Vercel
- Netlify
